# Dividend FIRE Simulator

Windows 배포용 FIRE 시뮬레이터입니다.

## 무설치 사용 (추천)

**[⬇️ DividendFIRE-Portable-v1.0.4.zip 다운로드](https://github.com/galcampdan/DividendFIRE/releases/download/v1.0.4/DividendFIRE-Portable-v1.0.4.zip)**

1. ZIP 압축을 풉니다.
2. `DividendFIRE` 폴더 안의 `DividendFIRE.exe`를 실행합니다.
3. 설치 과정이나 Python 설치는 필요하지 않습니다.
4. 프로그램 폴더는 통째로 유지하세요.

설정은 프로그램 폴더가 아니라 `%LOCALAPPDATA%\DividendFIRE\settings.json`에 저장됩니다.

## 설치형 버전

설치형이 편하면 아래 EXE를 사용하면 됩니다.

**[DividendFIRE-Setup-v1.0.4.exe 다운로드](https://github.com/galcampdan/DividendFIRE/releases/download/v1.0.4/DividendFIRE-Setup-v1.0.4.exe)**

**[전체 최신 Release 보기](https://github.com/galcampdan/DividendFIRE/releases/latest)**

> 현재 배포파일은 코드서명되지 않았기 때문에 Windows SmartScreen에서 "알 수 없는 게시자" 경고가 표시될 수 있습니다. 실제 악성코드 탐지가 뜨는 경우에는 실행하지 마세요.
