# Dividend FIRE Simulator

Windows 배포용 FIRE 시뮬레이터입니다.

## 설치

### Windows

**[⬇️ 최신 버전 다운로드 / 설치](https://github.com/galcampdan/DividendFIRE/releases/latest)**

현재 최신 설치파일:

**[DividendFIRE-Setup-v1.0.2.exe 다운로드](https://github.com/galcampdan/DividendFIRE/releases/download/v1.0.2/DividendFIRE-Setup-v1.0.2.exe)**

다운로드한 `DividendFIRE-Setup-v1.0.2.exe`를 실행하면 됩니다. Python 설치는 필요하지 않습니다.

> 현재 설치파일은 코드서명되지 않았기 때문에 Windows SmartScreen에서 "알 수 없는 게시자" 경고가 표시될 수 있습니다. 실제 악성코드 탐지가 뜨는 경우에는 실행하지 마세요.
